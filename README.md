# NOVA'S NEEDS

Pakistan's everyday online store — Home & Living, Women's Beauty & Cosmetics,
Baby & Kids, School & Stationery, Daily Essentials, and Gifts & Offers.

Live test site (GitHub Pages): https://novasneeds.github.io/novasneeds/

Custom domain coming soon: novaneeds.shop (planned — not yet connected)

## How to order

1. Browse products and pick a variant and quantity.
2. Place your order — it is confirmed on WhatsApp.
3. Pay with Cash on Delivery when your parcel arrives.

WhatsApp / Chat Support: +1 516-259-3218

## Delivery (Pakistan)

- Standard delivery: Rs 250
- Free standard delivery on orders over Rs 5,000
- Express delivery: Rs 450

## About this repository

This repository hosts the NOVA'S NEEDS storefront as a static site
(`index.html`) for testing on GitHub Pages. Orders are handled via WhatsApp —
there is no online card payment on this test site.
